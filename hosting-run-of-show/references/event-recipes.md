# Reusable event recipes
These are workflow recipes, not imposed traditions or UI theme mappings.

## Dinner
Choose service style -> approved headcount -> source-linked menu -> equipment/storage check -> pantry/shopping -> accepted setup/prep owners -> timed serving -> leftovers/cleanup. Provide host run sheet and a separate short guest note.

## Cookie swap
Agree how many portions each person brings/takes -> baking or non-baking contribution slots -> ingredient/label and cross-contact questions privately -> packaging supplies -> table labels that disclose only approved information -> exchange -> cleanup. Label factual ingredients; never certify 'allergy safe'.

## Open house
Define attendance window and restocking plan -> arrival/parking -> cold/hot holding with a responsible person -> activity/quiet seating if requested -> waste/cleanup. Don't treat rolling arrivals as one simultaneous meal count.

## Wrapping gathering
Agree whether people bring gifts or only help wrap -> shared supplies -> private gift storage/labels -> separate workstations -> transport home. A public signup must not reveal gift recipients or contents.
