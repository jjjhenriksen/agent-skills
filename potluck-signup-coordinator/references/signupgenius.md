# SignUpGenius adapter limits
Checked 2026-11-10.
The official potluck page advertises free slots/quantities and email reminders; guest signup needs no account. Custom questions/text reminders and other features may require paid plans: inspect actual entitlements, never upgrade automatically.

The current Terms of Service include a prohibition on making automated use of the site/services. Therefore this skill does NOT ship unattended browser creation/scraping. Obtain provider permission or a verified permitted integration before enabling browser control. A user's login alone doesn't resolve provider permission. Never bypass CAPTCHA, bot restrictions or access controls.

Useful now: author the exact signup packet (title, date/timezone, categories, quantities, serving targets, approved instructions, setup/cleanup slots), let the organizer enter/publish it, then process supplied exports. Remember export completeness and stable IDs; a disappeared row in a partial export isn't cancellation. No terms acceptance, new account or payment actions in this workflow.

If provider permission is later documented: inspect the logged-in organizer identity and existing signup, create/edit a draft by observed controls, verify title/timezone/quantities/visibility, publish/share only within event authority, retain canonical URL and read back. After uncertainty inspect existing drafts instead of duplicating. Use the current browser tool's own skill; never hardcode selectors from this design.

Native signup reminders and agent reminders must not both own the same notification. APIs advertised by Enterprise and Zapier slot-fill events do not establish that a full signup-creation endpoint exists or that cancellations are covered.
